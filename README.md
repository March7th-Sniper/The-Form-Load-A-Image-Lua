# The-Form-Load-A-Image-Lua
Cheat Engine Lua The Form Load A Image (使用Cheat Engine的Lua,窗口加载一个图片)
WARNING(警告):
EN:This Lua script uses a GET request. If the image hasn't finished loading, Cheat Engine will freeze. If the image is too large, it will automatically adjust to the screen resolution.
zh_CN:(这个Lua脚本使用get请求,如果图片没有加载完成,Cheat Engine会卡住,如果图片尺寸过大,他会自动适应显示器分辨率大小.)
